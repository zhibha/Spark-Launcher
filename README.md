# Spark Launcher

Spark Launcher is an open-source, non-commercial third-party launcher for **Minecraft: Java Edition** on Android devices.

## 📖 About The Project

This project aims to provide a smooth, legitimate, and highly customizable way for players to experience Minecraft: Java Edition on their mobile devices. 

**Project Status:** Early Development / Work in Progress.

## 🔐 Microsoft Authentication

Spark Launcher uses the official Microsoft OAuth 2.0 Device Code Flow to allow users to log in with their legitimate Microsoft accounts. This integration is designed to:
- Verify game ownership.
- Allow players to join online-mode (authenticated) multiplayer servers.
- Retrieve user profiles and skins securely.

## ⚖️ Disclaimer & Compliance

- **Not Official:** Spark Launcher is **NOT** an official Minecraft product. It is not approved by or associated with Mojang or Microsoft.
- **Non-Commercial:** This project is completely free, open-source, and strictly non-commercial. There is no advertising, no paid subscriptions, and no in-app purchases.
- **EULA Compliant:** This launcher does not distribute the game files, bypass authentication, or promote piracy. Users must own a legitimate copy of Minecraft: Java Edition to play.

## 🛠️ Built With

- Kotlin / Android SDK
- OpenJDK 17 (PojavLauncher base engine)
- MobileGlues (Graphics translation layer)
