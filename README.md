## 📖 About The Project

**Spark Launcher** is a modern, high-performance third-party launcher designed to bring the authentic PC experience of **Minecraft: Java Edition** to Android devices. 

Built with Kotlin and the Android SDK, it utilizes OpenJDK 17 and MobileGlues for high-performance graphics translation. Whether you are playing on a high-end tablet or a mid-range phone, Spark Launcher aims to provide a smooth, customizable, and legitimate gaming experience.

## ✨ Key Features

- **Official Microsoft Login**: Secure OAuth 2.0 Device Code Flow authentication. Log in with your legitimate Microsoft account to verify game ownership, access online-mode multiplayer servers, and load your official skins.
- **Modern Technical Stack**: Powered by OpenJDK 17 and optimized rendering engines (MobileGlues).
- **Highly Customizable**: Full control over game directories, memory allocation (RAM), and custom JVM arguments for power users.
- **100% Free & Open Source**: No ads, no paid subscriptions, and no hidden fees. Distributed under the GPL-3.0 License.
